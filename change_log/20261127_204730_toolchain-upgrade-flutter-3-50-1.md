# Change log: toolchain upgrade to Flutter 3.50.1 and Kotlin 2.4.20

Implements plan: `plans/20261127_202437_toolchain-upgrade-flutter-3-50-1.md` (partly — see "Not done").

## What changed

- `android/settings.gradle.kts` — Kotlin Gradle Plugin 2.4.10 → 2.4.20.
- `pubspec.yaml` — Dart SDK constraint `^3.13.5` → `^3.14.0` (the Dart in Flutter 3.50.1).
- `pubspec.lock` — regenerated by `flutter pub get`.
- `.github/workflows/ci.yml` — `flutter-version` 3.47.6 → 3.50.1.
- `CLAUDE.md`, `AGENTS.md` — project identity table: Flutter 3.50.1, Dart `^3.14.0`,
  Kotlin Gradle Plugin 2.4.20.
- `README.md` — Flutter badge and setup text say 3.50.

AGP 9.4.1 and Gradle 9.8.0 were already in place; no change.
`docs/implementation_progress.md` was left as it is (history record).

## Checks

- `dart format` — no changes.
- `flutter test` — all 753 tests pass.
- `flutter build apk --flavor dev --debug` — builds with Kotlin 2.4.20 and AGP 9.4.1.
  Gradle daemons stopped, leftover daemon processes ended.
- Build warning: the `screen_protector` plugin still applies the Kotlin Gradle Plugin;
  a future Flutter version will refuse this. No newer `screen_protector` exists yet.

## Not done

- `flutter analyze` shows 2 deprecation notices in the generated
  `lib/l10n/app_localizations.dart`: its `localizationsDelegates` list names
  `GlobalMaterialLocalizations` / `GlobalCupertinoLocalizations` from the old SDK
  package. `flutter gen-l10n` in 3.50.1 still writes them this way, so a hand edit would
  be lost. The app does not use that list (it uses `LocaleConfig.localizationsDelegates`).
  The fix is left for the user to decide, in a new plan.
