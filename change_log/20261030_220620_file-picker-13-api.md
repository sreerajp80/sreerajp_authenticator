# Update backup import to the file_picker 13 API

Plan: `plans/20261030_220101_file-picker-13-api.md`

## What changed

- `lib/services/export_import_service.dart`: `importAccountsEncrypted` now calls
  `FilePicker.pickFile()` instead of `FilePicker.platform.pickFiles()`. This fixes the release build
  error "Member not found: 'platform'". Version 12 of `file_picker` removed that member.
- The method still returns `null` when the user cancels. `readBackupFile` did not change, so the
  size limit, decryption and validation stay the same.

## Checks

- `flutter analyze`: no issues.
- `flutter test`: all 580 tests pass, including the 4 test files that could not load before.

- The phone checklist in the plan has not been done. Tests do not cover the system file picker.
