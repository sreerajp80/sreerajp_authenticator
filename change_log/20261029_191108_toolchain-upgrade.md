# Upgrade the Android toolchain (adoption Phase 3)

Implements plan: `plans/20261029_185250_toolchain-upgrade.md`
(part of `plans/20261029_183929_adopt-updated-guidelines.md`, Phase 3)

## What changed

| Tool | Before | After |
|---|---|---|
| Dart SDK constraint (`pubspec.yaml`) | `^3.12.2` | `^3.13.5` (Flutter 3.47.6) |
| Android Gradle Plugin (`android/settings.gradle.kts`) | 8.11.1 | 9.4.1 |
| Kotlin Gradle Plugin (`android/settings.gradle.kts`) | 2.2.20 | 2.4.10 |
| Gradle (`android/gradle/wrapper/gradle-wrapper.properties`) | 8.14 | 9.8.0 |
| Java source / target | 11 | 17 |
| `minSdk` | Flutter default | 29 |

`android/app/build.gradle.kts`:

- Replaced the old `kotlinOptions { }` block with a top-level
  `kotlin { compilerOptions { jvmTarget.set(JvmTarget.JVM_17) } }` (engineering standard §5.3).
- Removed `id("kotlin-android")`; the Flutter Gradle plugin applies Kotlin while
  `android.builtInKotlin=false`.
- Replaced `project.exec { }` (removed in Gradle 9) with injected `ExecOperations` in the
  `generateBuildMetadata` task.
- Set `minSdk = 29` with a comment pointing to `docs/PROJECT_PROFILE.md` §3.
- The custom APK file name block still works on AGP 9; no change.

Other files:

- `pubspec.lock` — updated by `flutter pub get` (not edited by hand).
- `analysis_options.yaml` — Flutter added an `analyzer: exclude:` list (build and platform
  folders) by itself during `flutter pub get`. Kept.
- `lib/utils/build_date.g.dart` — regenerated by the build.
- `CLAUDE.md`, `AGENTS.md` — updated the platform, Flutter, Dart and Android toolchain rows.

`android/gradle.properties` and `docs/guidelines/` were not changed.

## Note on the guideline

Engineering standard §5.3 says to use the versions Flutter generates. Flutter 3.47.6 knows up to
AGP 9.2, Gradle 9.3.1 and Kotlin 2.4.0. The owner chose newer versions, which the owner's other
apps already use. The build printed no "newer than known" error.

## Checks

- `flutter pub get` — OK.
- `flutter analyze` — no issues.
- `flutter test` — all 229 tests passed.
- `flutter build apk --flavor dev --debug` — built.
- Gradle daemons stopped; no `GradleDaemon` or `KotlinCompileDaemon` process left.

## Found, not fixed here

- Build warning: six plugins (`file_picker`, `mobile_scanner`, `package_info_plus`,
  `screen_protector`, `share_plus`, `shared_preferences_android`) still apply the Kotlin Gradle
  Plugin. Future Flutter versions will fail on this. Fix later by updating those plugins.
- `dart format --set-exit-if-changed .` reports 43 files that need formatting (existed before
  this change). To be fixed in a separate formatting-only change.
- The `material_ui` migration gets its own plan.
