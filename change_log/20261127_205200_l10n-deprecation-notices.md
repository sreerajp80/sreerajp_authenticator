# Change log: clear the 2 deprecation notices in the generated l10n file

Implements plan: `plans/20261127_204849_l10n-deprecation-notices.md`
Also closes the open item of `plans/20261127_202437_toolchain-upgrade-flutter-3-50-1.md`
(see `change_log/20261127_204730_toolchain-upgrade-flutter-3-50-1.md`, "Not done").

## What changed

- `l10n.yaml` — added `header: "// ignore_for_file: deprecated_member_use"` with a comment
  saying why. The generated `localizationsDelegates` list in `lib/l10n/app_localizations.dart`
  names the old SDK `GlobalMaterialLocalizations` / `GlobalCupertinoLocalizations`
  (deprecated since Flutter 3.47), and `flutter gen-l10n` 3.50.1 has no option to change that.
  The app does not use that list; it uses `LocaleConfig.localizationsDelegates`.
- `lib/l10n/app_localizations.dart`, `app_localizations_en.dart`, `app_localizations_ml.dart`,
  `app_localizations_sa.dart` — regenerated by `flutter gen-l10n`; each now starts with the
  header line. Not edited by hand.

The existing `// ignore_for_file: type=lint` in the generated files did not cover this,
because `deprecated_member_use` is an analyzer warning, not a lint.

## Checks

- `dart format` — no changes.
- `flutter analyze` — **No issues found.**
- `flutter test` — all 753 tests pass.
- No Gradle build (Dart-only change).

## Note for later

When a future `flutter gen-l10n` writes the delegates from `material_ui` / `cupertino_ui`,
this header can be removed from `l10n.yaml`.
